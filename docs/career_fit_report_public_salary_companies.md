## Lectura rapida

Tu mejor encaje no es "junior backend generico", sino producto tecnico donde puedas vender muy bien la combinacion backend + AI aplicada + autonomia:

1. Landbot - encaje excelente por AI agents, backend, RAG/evaluacion y producto. Es senior/stretch.
2. Tinybird - encaje excelente por Python, TypeScript, developer tools, SQL, AI/MCP y producto para developers.
3. Mercadona Tech - encaje muy solido por Python, PostgreSQL, Docker, producto, testing y cultura de ingenieria. Requiere Valencia hibrido y piden 5+ anos.
4. haddock - encaje fuerte por AI workflows en produccion, producto, backend y ownership. Tambien senior/stretch y Barcelona hibrido.
5. Factorial/Itnig - muchas oportunidades de product engineering y AI, especialmente si aceptan potencial aunque varias son senior.
6. Cabify - buen backend distribuido y cultura tecnica; stack diferente, pero valoran adaptabilidad.
7. RevenueCat / Docker / Kraken / Attio / Phantom - muy buenas empresas y salarios, pero la mayoria de roles actuales son senior, US/EMEA restringido o con barrera de experiencia alta.

## Estrategia recomendada

Aplicaciones de primera ola:

1. Landbot - AI Engineer Agentic Systems & Backend.
2. Tinybird - Product Engineer SDK/CLI.
3. Mercadona Tech - Backend Engineer.
4. Factorial - AI Engineer API & Integrations y Product Engineer.
5. haddock - AI Engineer y Product Engineer, solo si quieres plantearlo como apuesta stretch.
6. Cabify - Backend Software Engineer.

Como posicionarte:

- Titular: "Software Engineer focused on AI product and backend systems".
- Proyecto estrella: Cerno, enfatizando RAG, FastAPI, PostgreSQL, Docker, OpenAI, evaluacion de calidad y producto usable.
- Para Tinybird: subrayar developer experience, Python, TypeScript/Next.js, SQL/PostgreSQL, MCP/RAG y autonomia.
- Para Landbot/haddock/RevenueCat/Owner: subrayar LLM systems, tool use, RAG, evaluacion, observabilidad, costes y production readiness.
- Para Mercadona/Cabify: subrayar backend limpio, testing, Docker, PostgreSQL, despliegue, producto y aprendizaje rapido de stack.

## Riesgos y gaps a cerrar

- Muchas mejores oportunidades piden seniority real de 5+ anos. Tu CV debe compensarlo con proyectos muy concretos, demos desplegadas, tests y decisiones tecnicas.
- Falta experiencia profesional en empresa en el CV. Conviene anadir una seccion "Selected technical impact" o "Engineering highlights" con metricas de Cerno y TFG.
- Para roles AI agents, prepara una mini demo o README donde expliques arquitectura, evaluacion, trazas, fallbacks y costes.
- Para backend senior, prepara historias STAR sobre testing, modelado de datos, CI/CD, errores en produccion simulados y trade-offs.
